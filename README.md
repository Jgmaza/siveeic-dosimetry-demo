# Dose Ledger Demo (SIVEEIC-inspired)

Sanitized portfolio demo of a unified dosimetry ledger: historical + new intakes, dual-write preview, NR/NP flags, role scopes, and report summaries.

- **Stack:** Vite + React + TypeScript + Tailwind + MSW
- **No real backends**, workers, or institutional hosts

## Local

```bash
npm install
npm run dev
```
