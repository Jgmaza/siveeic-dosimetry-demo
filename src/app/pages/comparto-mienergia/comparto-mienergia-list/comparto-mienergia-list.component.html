Carga masiva

Para realizar el cargue masivo de datos:
* Descargue el formato de reporte.
* Diligencie el formato, indicando el servicio Público y detalles del servicio.
* Diligencie los campos de datos decimales, usando el punto (.) como carácter de separación.
* Guarde el archivo en formato CSV, usando la coma ( , ) como carácter de separación.
* Ingrese al formulario en la opción "Cargar datos masivos", seleccione el périodo y el archivo que diligenció.
