Plantilla & Instrucciones

Para realizar el cargue masivo de datos:

- Paso 1. Descargue el formato: Haga clic en "Descargar Formato Excel" para obtener la plantilla Formato_Reporte_Dosimetria.

- Paso 2. Diligencie el formato: Lea los encabezados de cada columna, los cuales indican el dato requerido y su formato. Use las listas desplegables cuando estén disponibles. Para valores decimales, emplee el punto (.) como separador.

- Paso 3. Cargue y valide: Arrastre el archivo o haga clic en la zona de carga. El sistema verificará los datos automáticamente. Si hay inconsistencias, se generará un reporte de errores para que pueda corregirlos antes de continuar.

- Paso 4. Confirme el cargue: Una vez el sistema no detecte errores, haga clic en "Cargar Datos Masivos" para registrar la información definitivamente.

Nota: Antes de diligenciar, consulte el documento de instrucciones disponible en el botón "Descargue de Instrucciones"
