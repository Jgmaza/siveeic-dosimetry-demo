Carga masiva

Para realizar el cargue masivo de datos:
* Descargue el formato de reporte.
* Diligencie el formato, indicando el código del municipio y la cantidad de medidores instalados.
* Guarde el archivo en formato CSV, usando punto y coma ( ; ) o la coma ( , ) como carácter de separación.
* Ingrese al formulario en la opción "Cargar datos masivos", seleccione el périodo y el archivo que diligenció.
